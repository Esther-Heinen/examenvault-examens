# examenvault-examens

Kopieën van de opgavenboekjes en correctievoorschriften van de centrale examens vwo (2018-2026) die
op [examenvault.nl](https://examenvault.nl) naar worden verwezen, zodat ze in het tweede paneel (split-view) kunnen openen.

**Bron:** [examenblad.nl](https://www.examenblad.nl), College voor Toetsen en Examens (CvTE). De bestanden zijn
ongewijzigd overgenomen. Alle rechten van de examens berusten bij de oorspronkelijke rechthebbenden (CvTE en,
voor de bronnen in de opgaven, de genoemde bronhouders); zie de bronvermelding achterin elk examen.

Opbouw: `vwo/<vak>/<jaar>-<tijdvak>-opgaven.pdf` en `vwo/<vak>/<jaar>-<tijdvak>-correctievoorschrift.pdf`.
`ophalen.py` haalt ze op (lijst uit `examenpaginas.json` van de site-bron).
